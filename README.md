# LungeSmash (Fabric 1.21.11)

Spear + mace combo HUD (client-side, display only). Shows next to your crosshair while you hold a
spear or a mace: spear jab readiness and Lunge level, how many lunges your food can pay for, and a
"SWAP TO MACE" prompt with predicted smash damage when you fall with the spear in hand.
Toggle with /lungesmash. Needs Fabric Loader 0.18.2+, Fabric API, Java 21.
